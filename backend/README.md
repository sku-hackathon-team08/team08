# 백엔드

백엔드 코드가 위치할 폴더입니다. 기능별 모듈을 하나의 애플리케이션에서 실행하는 모놀리식 구조를 사용합니다. FastAPI를 사용하고 uv로 가상환경·의존성을 관리합니다.
로컬 DB는 SQLite이며 배포 DB로 PostgreSQL을 검토하고 있습니다.
선택별 확정 상태와 남은 결정은 [아키텍처](../docs/architecture.md#백엔드-환경과-db)에서 관리합니다.

아직 앱 코드·의존성 설정·DB 연결은 없습니다.
초기 스캐폴딩 후 실제 설치·실행·검증 명령을 이 문서에 추가합니다.

작업 전 [문서 지도](../docs/index.md)에서 관련 기능·기술 명세를 확인합니다.
프로젝트 소개는 [루트 README](../README.md)에 있습니다.
