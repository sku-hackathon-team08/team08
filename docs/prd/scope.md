## 검증을 전제로 하는 범위

접근 경로 1개 표시를 제품 목표로 유지하지만, 브이월드의 경로 탐색 제공 여부·사용할 제공자·도보 적합성은 미검증입니다. 지도를 사용할 수 있다는 이유만으로 경로 기능도 제공된다고 간주하지 않습니다. [미정 목록](spec-review.md)에서 추적합니다.

## 데모 표현과 제외 범위

- 가시권·히트맵·관공서 연계는 모의 시연 범위입니다. 실제 분석·신고 전달을 제공한다고 표시하지 않습니다.
- 사용자 구역 그리기·게이트 배치 기능은 제외합니다. 제공자의 사전 구축 업무로 대체합니다.
- 긴급 롱프레스 즉시 신고는 제거합니다. 긴급 유형 자체는 유지합니다.
- QR 진입, 유사 신고 자동 병합·관련 신고, 자동 구역 담당자 배정, 별도 관리자 계층·승인 단계, 결제·다국어, 다크 모드·2D 지도 대체는 이번 범위에서 제외합니다.
- 신고 취소는 기록의 물리 삭제가 아닙니다. 별도 목록 숨김 기능은 두지 않습니다.
- 담당자 직접 이관·종결 신고 재개는 포함하지 않습니다. 담당 배정 취소 후 재배정은 가능합니다.

## 기술 명세의 경계

이번 갱신은 기획 내용입니다. 기능 API의 경로·요청·응답·오류, ERD·테이블·저장 제약, 실시간 방식·인증·파일 처리·지도 연동 계약은 확정하지 않습니다. 기존 저장소의 공통 기술 결정은 유지하고, 기획 게시 이후 API 명세를 별도 검토안으로 작성합니다.
