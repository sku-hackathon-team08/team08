## 해커톤 추가 확정 — 2026-09-11

정책별 사용자 확인으로 공통 행사 코드·역할 선택·기기 세션 유지, 분석 상한·실패 재시도, 동시성·지원 자동 종료, 한국 시간 통계·서버 PDF를 확정했습니다. 행사 신청·발급, GPS·구역 판정·접근 경로는 제외합니다. 현재 구현 범위는 [해커톤 계약](../api/hackathon.md)입니다. 아래 이전 미정 목록은 해당 계약에서 해소한 부분을 제외한 장기 운영·클라이언트 후속 검토에만 적용합니다.

## 이후 API 작성 범위

기획 게시 후 행사 진입 → 분석과 접수 → 관제 조회 → 담당·분류·완료·취소 → 지원 → 이력·리포트 순으로 API 검토안을 작성합니다. 권한·동시 동작·재전송의 기대 결과를 API 요청·응답·오류에 연결합니다.

현재 API 경로·필드·인증·동시성 방법·실시간 방식·ERD는 이 문서로 확정하지 않습니다. 미정 기획에 의존하는 API는 의존 항목을 표시하고 임의 기본값을 확정하지 않습니다. 저장소에 이미 채택된 공통 오류·네이밍 규칙 등은 별도 기준을 유지합니다.
