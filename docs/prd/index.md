# PRD — 제품 요구사항

> 상태: 미정. 서비스 결정 후 작성할 문서 모음입니다.

제품 요구사항은 주제별로 나눠 관리합니다. 이 문서는 목차이며 상세 내용은 아래 문서에서 작성합니다.

| 문서 | 다루는 내용 |
|---|---|
| [문제·사용자·목표](context.md) | 누구의 어떤 문제를 해결하고 어떤 가치를 제공하는지 |
| [MVP 범위·우선순위](scope.md) | 이번에 만들 기능, 우선순위, 제외 범위 |
| [성공 기준](success-criteria.md) | 제품 전체의 성공 조건과 데모에서 확인할 흐름 |

## 문서 경계

PRD는 제품의 목적과 범위를 정합니다. 기능별 화면 동작·예외·인수 조건은
[기능 명세](../features/index.md)에 작성하고, PRD에서는 해당 문서를 연결합니다.
API 요청·응답 계약은 [API 문서](../api/index.md), 데이터·외부 연동 계약은 [기술 명세](../specs/index.md)에서 관리합니다.

특정 주제가 길어지면 그 주제만 추가로 나누고 이 목차를 갱신합니다.
문서별로 검토 상태와 미결정 사항을 표시합니다. 관리 기준은 [SOT](../sot.md), 전체 문서는 [문서 지도](../index.md)를 참고합니다.
