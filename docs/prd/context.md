# 문제·사용자·목표

> PRD v1.2 · 2026-09-10 · 제품 방향 확정. 세부 미정 사항은 [미정 목록](spec-review.md)에서 관리합니다.

## 해결할 문제

축제 현장의 무전·구두 신고는 소음 속에서 내용과 위치가 누락되기 쉽고, 여러 관리자가 같은 신고를 중복 처리하거나 아무도 맡지 않는 상황이 생깁니다. 종료 후에도 누가 어떤 판단과 조치를 했는지 정리하기 어렵습니다.

**현장의 지금**은 스태프의 음성·텍스트 신고를 구조화하고 브이월드 3D 지도에 연결하여, 관리자가 담당 배정부터 지원·완료까지 함께 확인하는 축제 안전 대응 서비스입니다.

## 대상 사용자와 이용 환경

- 스태프: 행사 코드·이름·소속 팀으로 진입하여 현장에서 신고하고 자신의 신고 처리 상태와 활동 리포트를 확인합니다. **모바일 앱으로 개발합니다.** 앱 구현 방식·지원 OS는 미정입니다.
- 관리자: 행사 코드·이름으로 진입해 태블릿 중심의 관제 화면을 사용합니다. 같은 행사 관리자는 동등한 역할이며, 행사 신청자에게 별도 상위 권한을 주지 않습니다. 관리자 화면의 앱·웹 배포 방식은 미정입니다.
- 서비스 제공자(우리 팀): 행사에 사용할 구역·게이트 데이터를 사전에 구축합니다. 이용자는 행사 신청 후 발급받은 코드로 구축 데이터와 지도 데이터가 결합된 행사를 확인합니다.

스태프의 소속 팀은 자유 입력 정보이며 사전 배정 구역과 연결하지 않습니다. 신고 위치는 [고정 위치](../features/report-intake.md#오늘-데모의-고정-위치)를 사용하고 이번 해커톤에서는 구역 판정을 하지 않습니다. 현재 구현 범위에서 GPS는 사용하지 않으며 GPS 미수신 조사 #46은 범위에서 제외합니다.

## 목표와 제품 원칙

1. 스태프가 현장을 길게 설명하거나 지도에서 수동으로 위치를 찾는 부담을 줄입니다.
2. 관리자가 신고 위치·원문·유형·위험도·현재 담당자를 함께 확인하고 조치합니다.
3. 담당·지원·분류 수정·완료·취소 이력을 남겨 인수인계와 사후 확인에 사용합니다.
4. AI는 내용을 정리하고 위험 신호를 추출합니다. 위험도는 규칙 기반 제안이며, 최종 신고 전 스태프가 확인하고 담당 배정 시 관리자가 분류를 확정합니다.
5. 원문과 수정 결과, AI 제안과 사람의 확인을 구분합니다. 화면 열람이나 AI 분석만으로 신고가 접수되거나 담당자가 배정되지 않습니다.

실제 사고 예방 효과나 외부 지도·경로 기능의 동작은 아직 검증한 결과가 아닙니다.
