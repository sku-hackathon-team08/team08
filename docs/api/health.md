# 앱 상태 확인

> 상태: 계약 확정·구현. [API 목록](index.md) · [아키텍처](../architecture.md)

| 항목 | 내용 |
|---|---|
| 메서드·경로 | `GET /health` |
| 목적 | HTTP 요청에 앱이 응답하는지 확인 |
| 인증 | 필요 없음 |
| 요청 | 경로·쿼리 매개변수와 본문 없음 |
| 성공 | `200 OK`, `application/json` |

```json
{"status": "ok"}
```

`status`는 문자열 `"ok"`입니다. 이 응답은 앱의 응답 가능 여부만 나타냅니다.
DB·AI API·외부 서비스의 준비 상태나 전체 기능의 정상 동작을 보장하지 않습니다.
앱 시작 시 DB 연결은 확인하지만, `/health`는 이후의 DB 장애를 검사하지 않습니다. 별도 준비 상태 확인은 필요한 시점에 검토합니다.

이 API에 정의된 업무 오류는 없습니다. 앱이 실행되지 않거나 연결할 수 없으면 정상 응답을 받을 수 없습니다.

검증 기준은 인증 없이 호출했을 때 상태 코드·콘텐츠 유형·본문이 위 계약과 일치하는 것입니다.
실행 방법은 [백엔드 README](../../backend/README.md), 테스트는 [test_health.py](../../backend/tests/integration/test_health.py)에 있습니다.
