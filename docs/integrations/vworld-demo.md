# 서울월드컵경기장 콘서트 데모 작업 기준

> 상태: **현재 가상 배치와 좌표를 후속 데모 작업의 기준으로 채택** (사용자 확인: 2026-09-11).
> 실제 공연 도면·실측 출입구·수용 인원을 확정한 것이 아닙니다. 제품 API·DB 계약과 구분합니다.

## 이 데이터로 진행할 작업

서울월드컵경기장에 미리 준비한 콘서트 배치를 표시하고, 같은 구역·게이트 데이터로
지도 표시와 구역 판정, 신고 위치 시연을 진행합니다. 장소 선정과 기본 배치 작업을 다시 시작하지 않고
아래 파일과 좌표를 사용합니다. 한 행사를 미리 준비해 행사 코드로 진입하는 데모 흐름을 전제로 합니다.
행사 생성·코드 인증·신고 API는 이 지도 시연에 구현되어 있지 않으며 후속 연동 대상입니다.
앱을 종료했다 다시 실행했을 때의 로그인·행사 유지 방식은 보류합니다.

## 소유권과 조회 흐름

행사에 연결된 장소·모델 배치·구역·게이트·데모 지점의 소유자는 **백엔드**입니다.
프론트 담당자는 행사 ID로 지도 API를 호출하고 응답을 렌더링합니다. 이 PR에는 프론트 구현·SDK 설정을 포함하지 않습니다.

1. 프론트 담당자는 데모 행사 ID `69cbb93b-d6cb-5785-a7c8-e606c7279d3d`로 API를 호출합니다.
2. `GET /api/v1/demo/events/{eventId}/map`으로 모델 URL·위치·회전·구역·게이트·데모 지점을 받습니다.
3. 모델과 내려받기 파일은 같은 행사의 `/assets/{assetName}`에서 받습니다.
4. 지형에 따른 높이 계산·카메라·선택·핀 표시는 프론트 어댑터가 처리합니다.

현재는 백엔드가 소유한 **읽기 전용 데모 seed 파일**을 저장소 계층에서 조회합니다. 업무 DB에 저장하는 구현은 아닙니다.
모르는 행사 ID는 지도와 파일 모두 404이며, 허용된 세 파일 외 경로는 제공하지 않습니다.
이 경로는 공개 가상 데모 전용입니다. 인증된 `events/current/map`을 구현한 것으로 간주하지 않습니다.
[데모 API 계약](../api/demo-map.md)을 참고합니다.

| 생성 파일 | 사용처 |
|---|---|

후속 연동은 생성된 `id`로 구역을 참조합니다. 좌표는 WGS84이며 GeoJSON 배열 순서는 **[경도, 위도]**입니다.
변경할 때는 배치 원본을 수정하고 네 파일을 함께 재생성합니다.

## 첫 시연에 사용할 한 점

빨간 `데모 지점`은 **플로어 A 내부**에 표시합니다. 이 값을 후속 지도 표시·신고 시연의 첫 위치로 사용합니다.

```json
{
  "lng": 126.8970733,
  "lat": 37.5683536
}
```

- GeoJSON 좌표: `[126.8970733, 37.5683536]`
- 연결할 구역 ID: `aa9d260d-0125-5c81-a99c-4cd24d0ae015` (플로어 A)
- 마커 입력: 지도 API의 `demoPoint` 필드. 렌더링 구현은 프론트 담당 범위입니다.
- 기대 동작: 해당 좌표를 표시하면 플로어 A 내부에 위치하며, 구역 판정에서도 A로 분류됩니다.

### 높이 적용

브이월드 어댑터에서 이 점의 높이는 **`modelGroundHeight + 0.44`m**입니다.
`modelGroundHeight`는 모델 바닥 범위 15개 지형 표본과 기준 높이에서 계산하는 런타임 값이며,
고정 해발고도가 아닙니다. 데모 API의 `demoPoint.surfaceOffsetMeters`로 오프셋 0.44를 받습니다. `0.44`는 이 데모의 바닥·선택 표면에 맞춘 오프셋입니다.

처음 적용했던 `+2m`는 점이 바닥에서 떠 보여 제거했습니다. 점은 높이 계산 후 표시하고 지형 갱신 시 함께 보정합니다.
다른 렌더러에 연동할 때는 경도·위도를 그대로 사용하되, 이 데모 모델의 바닥 표면에 맞춰 높이를 계산합니다.
GLB의 Y-up과 지도상의 위도/고도를 혼동하지 않습니다. Cesium 어댑터는 `upAxis=Y`, `forwardAxis=X`를 사용합니다.

## 백엔드 실행과 프론트 전달

저장소 루트에서 다음 명령으로 실행합니다. 백엔드의 저장된 데모 데이터 조회에는 브이월드 키가 필요하지 않습니다.

```sh
uv run --directory backend python scripts/build-concert.py  # 배치 수정 시
uv run --directory backend uvicorn app.main:app --host 127.0.0.1 --port 8001
```

지도 조회:

```sh
curl http://127.0.0.1:8001/api/v1/demo/events/69cbb93b-d6cb-5785-a7c8-e606c7279d3d/map
```

프론트 담당자에게 [API 계약](../api/demo-map.md), 행사 ID, `model.uri`와 배치 정보,
구역·게이트·`demoPoint`를 전달합니다. 브이월드 SDK·키 설정·API 프록시 또는 CORS 연동·카메라·표시는
프론트 통합 단계에서 구성합니다. 반환되는 상대 URL은 백엔드 origin 기준입니다.
프론트 구현과 npm 의존성·Vite 설정은 이 PR에서 변경하지 않습니다.

## 브이월드 연동과 API 경계

- SDK: `https://map.vworld.kr/js/webglMapInit.js.do`, version 3.0.
- 브이월드 렌더러 구현은 프론트 담당 범위이며, 아래 내용은 별도 로컬 검증에서 확인한 참고 사항입니다.
- 건물 데이터: `https://cdn.vworld.kr/TDServer/services/map4/TG9ENA.json`.
- 기본 `facility_build` 래퍼는 관찰 당시 타일 1개에서 정체되어 숨겼습니다. SDK에 포함된 Cesium의
  `Cesium3DTileset`으로 같은 제공자 데이터를 직접 로드해 주변 입체 건물을 확인했습니다.
  수신 타일 수는 건물 수가 아니며 경기장 본체의 독립 3D 모델 제공 여부는 미확인입니다.
- PR #48 E05의 구역·게이트 표현을 참고했습니다. 이 문서의 데모 채택은 API 초안 전체 승인이 아닙니다.
  `model`, `color`, `status`, `dataVersion`, 면적 등 시연용 확장 필드는 후속 API·DB 계약에서 별도로 정합니다.

기본 생성기만 실행하면 상세 모델이 기본 모델로 바뀝니다. 상세 모델 재생성에는 위 명령을 사용합니다.
스크립트 재실행은 `.blend`의 수동 편집을 다시 생성한 내용으로 대체하므로 수동 작업은 다른 파일로 저장합니다.

초기 미리보기는 Cesium·OpenStreetMap과 타원체 평면 지형을 사용했습니다. 현재 브이월드 연결은 아래 절을 따릅니다. 모델 바닥은 0.3m에 놓고
데모 지점에는 API의 표면 오프셋을 더합니다. 브이월드의 지형 표본·건물·항공영상 연동은 포함하지 않습니다.
프론트 개발 서버에서 산출물 변경 시 화면이 자동 갱신되며 수동 모델 새로고침도 지원합니다.

### 돌출 무대 연장

사용자 요청에 따라 `seoul-concert-03-blender-03`에서 객석 중앙 돌출 무대를 폭 5m·높이 2m를 유지한 채 길이 10m에서 22m로 연장했습니다. 로컬 북쪽 좌표 16~38m이며, 본무대와 연결되는 끝은 고정했습니다. 하부 골조·상판 이음매·가림막·가장자리 조명을 함께 연장했습니다.

추가 연장 요청으로 `seoul-concert-03-blender-04`에서는 돌출 무대를 36m(로컬 북쪽 좌표 2~38m)로 늘렸습니다. 폭 5m·높이 2m는 유지하며 하부 골조·가림막·조명도 함께 연장했습니다.

### 브이월드 실제 3D 지도 연결

사용자가 제공한 브라우저용 키를 `frontend/.env.local`에 보관하고 `/map-preview`를 브이월드 전용 문서로 연결했습니다.
[공식 GLB 샘플](https://github.com/V-world/V-world_API_sample)과 같은 `vw.Map`·`ws3d.viewer`를 사용합니다.
항공영상은 브이월드 Satellite WMTS, 지형은 공식 SDK DEM 공급자, 주변 건물은 `TG9ENA.json` 3D Tiles입니다.

15개 지형 표본을 SDK 최대 레벨 15에서 조회하고 최고 높이에 0.5m를 더해 모델을 놓습니다. 모델 바닥 두께 0.28m를 고려한 여유 높이입니다. 모델·구역·게이트·데모 지점·카메라에 같은 기준 높이를 적용합니다.
표본 조회 실패 시 지형 연결 오류를 표시하며 평면 지형으로 조용히 대체하지 않습니다. 경기장 본체가 3D Tiles에 포함되는지는 제공 데이터에 따릅니다.
SDK 버전에 맞게 `Model.fromGltf`·`readyPromise`와 새 로더 API를 모두 지원합니다. SDK Worker 경로는 브이월드 원본 경로를 사용하며 로컬 Cesium Worker와 섞지 않습니다.

### 가림막 제거 (사용자 요청)

`seoul-concert-03-blender-05`에서는 본무대와 돌출 무대의 모든 가림막을 GLB·Blender 원본·생성 스크립트에서 제거했습니다. 하부 골조가 항상 노출되며, 미리보기의 가림막 표시 옵션도 제거했습니다. 무대 크기와 하부 보기 카메라는 유지합니다.
