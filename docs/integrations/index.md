# 외부 연동 명세

> 상태: 외부 서비스·제공자와의 연동 명세는 아직 미정입니다.

AI·인증 제공자 등 외부 시스템과 연결할 때 지켜야 할 기술적 약속을 관리합니다.
필요한 연동이 생기면 제공자 또는 연동 주제별 문서를 이 폴더에 만들고 아래 목록에 연결합니다.

## 명세 목록

아직 없음.

## 작성 대상

- 연동 목적·사용하는 제공자 API·인증 방법
- 외부 요청·응답과 내부 데이터의 매핑
- 호출 제한·타임아웃·재시도·중복 요청 처리 조건
- 필요한 스트리밍·웹훅·실패 응답 처리 규칙

위 항목은 작성 범위이며 사용하는 기능에 필요한 내용만 작성합니다. 실제 키·토큰 등 비밀 값은 문서에 기록하지 않습니다.

## 다른 문서와의 경계

- 사용자에게 보이는 동작·업무 규칙·인수 조건은 [기능 명세](../features/index.md)에 둡니다.
- 프론트와 백엔드 사이의 요청·응답·인증·오류·스트리밍 계약은 [API 명세](../api/index.md)에 둡니다. 여기서는 백엔드와 외부 제공자 사이의 연동을 다룹니다.
- 연동 결과를 저장하는 테이블·관계·제약은 [DB 명세](../db/index.md)에 두고 연결합니다.
- 시스템 구성·레이어·의존 방향은 [아키텍처](../architecture.md), 개발 방법은 [개발 가이드](../guides/index.md)를 따릅니다.

문서 추가·변경 시 [인덱스 갱신 기준](../sot.md#인덱스-갱신-기준)을 따릅니다.
