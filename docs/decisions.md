배포 DB로 PostgreSQL을 검토하고 있습니다. 아직 채택된 결정이 아니며, 관련 미정 항목은 [아키텍처](architecture.md#백엔드-환경과-db)에 기록합니다.

## PRD v1.2 기획 반영 · 2026-09-10

사용자 인터뷰와 최종 화면 플로우를 반영했습니다. [충돌 해소 기록](prd/spec-review.md)에 취소 권한·미확인 시간·제공자 구역 구축·분류 동시 확정·지원 수명·처리시간·앱 방향의 채택 결과와 근거 문서를 연결합니다. 지원요청 종료는 최종 번복 답변을 적용합니다.

이번 게시에서는 기획 내용만 확정 상태별로 정리합니다. API·ERD 초안은 확정하지 않으며 기획 게시 이후 별도 검토안으로 작성합니다. 기존 공통 기술 결정은 유지합니다. GPS 미수신 대응은 [TBD #46](https://github.com/sku-hackathon-team08/team08/issues/46)으로 보류합니다.

## 축제 API v0.1 작성 · 2026-09-10

사용자 요청으로 [PRD v1.2 기반 API 검토안](api/festival.md)을 작성했습니다. 경로·모델·권한·실패·재전송·지원 수명을 구체화했으며 기획 의존 미정은 [결정 목록](api/festival/review.md)에 연결합니다. API 채택·구현 완료 기록이 아니며 ERD는 변경하지 않습니다.
