# 기술 명세

백엔드의 기술 선택은 [아키텍처](../architecture.md)에 기록되어 있습니다.
기능 범위·API·데이터 계약은 아직 미정이며 작성된 상세 기술 명세는 없습니다.
필요한 계약이 생기면 주제별 문서를 이 폴더에 만들고 아래 목록에 연결합니다.

## 명세 목록

아직 없음.

## 작성 대상

- API 경로·요청·응답·오류 계약
- 데이터 모델·관계·제약
- 인증·외부 연동 등 파트 간 공유할 기술 계약

구체적인 경로·필드·라이브러리는 결정 후 작성합니다. 사용자 동작과 인수 조건은
[기능 명세](../features/index.md), 시스템 전체 구성은 [아키텍처](../architecture.md)에 둡니다.
문서 유지 방법은 [SOT](../sot.md)를 참고합니다.
