## 필수 규칙과 권장사항

- **필수 규칙 제안:** 팀에서 필수로 채택할지 검토할 항목입니다. 현재 확정된 규칙으로 취급하지 않습니다.
- **권장사항:** 작업 특성에 맞게 조정할 수 있는 기본 방법과 예시입니다.
- **추후 결정:** 기술 스택이나 팀 합의가 필요한 항목입니다.

채택한 필수 규칙은 해당 문서에서 확정 상태로 표시하고 중요한 합의는 [결정 기록](../decisions.md)에 남깁니다.
문서에 적힌 제안과 실제 린터·CI·브랜치 보호 설정은 구분합니다. 백엔드 CI를 구성했으며, [main 브랜치 보호](git-workflow.md#main-브랜치-보호)로 PR·CI 통과와 강제 push·삭제 방지를 적용합니다.
작업 방식이 권장안과 다르다는 이유만으로 추가 승인이나 작업 중단을 요구하지 않습니다.

## 다른 문서와의 관계

[SDD](../sdd.md)는 명세부터 PR까지의 전체 흐름을 안내하고, 이 가이드는 각 단계의 작업 방법을 설명합니다.
요구사항·API·DB·외부 연동 계약은 [SOT](../sot.md)가 연결하는 기준 문서에서 관리합니다.
현재 설치·실행·검증 명령은 [백엔드 README](../../backend/README.md)에 있습니다. [프론트 README](../../frontend/README.md)는 스택 확정 후 실행 안내를 추가할 진입점입니다.
