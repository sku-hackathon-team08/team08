# 행사 신청·코드 진입·지도 준비

> 상태: 제품 흐름 확정, 아래 미정 항목 제외. 관련: [제품 목적](../prd/context.md), [미정 목록](../prd/spec-review.md).

## 이용 흐름

1. 서비스 제공자가 행사 장소의 구역 경계와 게이트를 사전에 준비합니다.
2. 이용자가 행사를 신청합니다.
3. 행사 코드가 발급됩니다. 코드로 해당 행사의 준비된 구역 데이터와 지도 데이터를 연결합니다.
4. 스태프는 코드·이름·소속 팀, 관리자는 코드·이름을 입력해 해당 역할의 화면으로 진입합니다.
5. 관리자 화면은 행사 지도·구역·게이트와 신고를 표시합니다. 이용자에게 구역·게이트 편집 단계를 요구하지 않습니다.

행사 신청자는 다른 관리자와 동등합니다. 스태프 팀 이름은 소속 표시이며 구역 배정 정보가 아닙니다. 스태프에게 사전 담당 구역을 배정하거나 GPS 실패 시 배정 구역으로 대체하지 않습니다.

## 인수 조건

- AC-E01: 행사 진입 후 사용자 구역 편집 없이 사전에 구축한 지도·구역을 확인할 수 있습니다.
- AC-E02: 같은 행사 코드를 사용한 사용자는 자신의 역할에 맞는 화면으로 진입합니다. 다른 행사 데이터는 섞이지 않습니다.
- AC-E03: 소속 팀을 바꿔도 현재 구역을 팀 이름으로 결정하지 않습니다.
- AC-E04: 행사 신청자라는 이유로 추가 관리자 권한을 부여하지 않습니다.

## 미정

신청 입력 필드의 필수 조건, 코드 형식·만료·재발급·발급 처리 시점, 미지원 장소 처리, 행사와 구축 데이터의 매칭·갱신 정책, 행사 운영 시작 전 진입·신고 허용, 관리자 자격 확인·역할 선택·재접속 방식은 미정입니다. 코드 발급 이후 이용한다는 흐름만으로 즉시 자동 구축이나 무검증 관리자 접근을 확정하지 않습니다.
