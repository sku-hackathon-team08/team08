# 내 신고·활동 리포트

> 상태: 화면 구성과 평균 처리시간의 시작·종료 기준 확정. 세부 집계는 미정 표시를 따릅니다.

## 내 신고

스태프는 자신이 전송한 신고의 접수·처리중·완료·취소 상태와 처리 내용을 확인합니다. 다른 스태프의 개인 신고 내역에 접근하지 않습니다. 처리 상태는 화면에서 조용히 갱신하며, 진행 변경마다 새 푸시를 보내는 흐름은 포함하지 않습니다.

## 활동 리포트

최신 와이어프레임의 오늘·이번 주·전체 기간 탭, 프로필, 신고 요약 건수, 유형 분포, 상세 신고 카드, PDF 내보내기를 기준으로 합니다. 취소 기록은 지우지 않습니다. 프로필의 소속 팀을 담당 구역으로 해석하지 않습니다.

**평균 처리시간은 담당 배정부터 완료까지**를 기준으로 합니다. 접수 후 담당 배정을 기다린 시간은 포함하지 않습니다. 완료하지 않은 신고와 취소 신고를 완료 처리시간으로 취급하지 않습니다. 재배정이 발생한 신고의 시간 누적·최종 배정 기준 중 어느 것을 적용할지는 미정입니다.

PDF는 사용자가 자신의 활동 결과를 내보내는 제품 기능입니다. 파일 생성 위치·보관·다운로드 방식은 기술 미정입니다.

## 인수 조건

- AC-R01: 다른 스태프의 내 신고가 자신의 목록에 섞이지 않습니다.
- AC-R02: 취소 신고가 자신의 이력에 취소 상태로 남습니다.
- AC-R03: 접수 10:00·배정 10:05·완료 10:15인 단일 배정 신고의 처리시간은 10분입니다.
- AC-R04: 기간을 선택하면 해당 기간의 활동 결과와 세부 신고를 확인할 수 있습니다. 세부 포함 기준은 아래 미정 해소 후 검증합니다.

## 미정

이번 주의 시작일·시간대, 기간에 포함할 시각(접수/완료), 전일 비교 산식, 0건 표시, 평균 반올림, 재배정 집계, 관리자 개인 실적·지원 실적 포함 여부, 개인정보 보존 기간과 PDF 유효·삭제 정책은 미정입니다.
