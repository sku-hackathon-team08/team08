# 3D 지도·신고 목록·미확인

> 상태: 아래 관제 흐름·미확인 정책 확정. 지도 제공자 기능과 나머지 미정 항목은 별도 검토합니다.

## 관제 화면

제공자가 구축한 구역·게이트를 브이월드 3D 지도와 결합하고 신고 핀과 목록을 함께 표시합니다. 신고 상세에는 위치·원문·정리된 내용·유형·위험도·현재 담당·지원·이력을 확인할 수 있어야 합니다.

최근순·위험도순 정렬과 유형·상태 필터를 제공합니다. 전체·미확인·처리중·완료 현황을 요약합니다. 목록에서 신고를 선택해 지도 위치와 상세를 확인하고, 직접 처리하기 또는 권한에 맞는 후속 작업으로 이어집니다. 단순 조회는 신고 상태나 담당자를 바꾸지 않습니다.

## 미확인 시간 — 사용자 확정

담당자가 없는 **접수 상태**에서 최초 서버 접수 이후 아래 시간을 **초과**하면 미확인입니다.

| 위험도 | 미확인 기준 |
|---|---|
| 긴급 | 3분 초과 |
| 주의 | 10분 초과 |
| 일반 | 30분 초과 |

미확인 신고는 선택된 목록 정렬과 관계없이 상단에 표시합니다. 일괄 10분으로 통일하지 않습니다.

담당 배정 취소로 접수에 복귀해도 시간을 초기화하지 않습니다. 최초 접수 이후 처리중이었던 시간도 포함합니다. 예를 들어 긴급 신고를 접수 2분 뒤 맡았다가 접수 5분 뒤 해제하면, 복귀 즉시 미확인·목록 상단 대상입니다.

처리중인 신고 자체는 이 미확인 조건으로 분류하지 않습니다. 위험도 자동 승격은 아직 확정하지 않았으며, 시간이 지났다는 이유만으로 위험도를 자동 변경하지 않습니다.

## 지도·접근 경로의 한계

접근 경로 1개 표시는 요구 방향이며 제공자 지원 여부를 검증해야 합니다. 경로를 구할 수 없는데 임의 직선을 실제 이동 가능한 안전 경로처럼 표시해서는 안 됩니다. 기본 출발 게이트·이동 방식·실패 표시·갱신 조건은 미정입니다. 가시권·히트맵·관공서 전달은 모의 시연과 실제 기능을 구분합니다.

## 인수 조건

- AC-C01: 긴급 3분·주의 10분·일반 30분 경과 직전에는 미확인이 아니며 초과 후 접수 상태이면 상단 표시 대상입니다.
- AC-C02: 정렬을 바꿔도 미확인 우선 표시가 유지됩니다.
- AC-C03: 최초 접수 5분 된 긴급 신고의 담당 배정을 취소하면 즉시 미확인으로 표시합니다.
- AC-C04: 신고 취소 후 핀·관제 목록에서는 빠지고 기록은 유지됩니다.
- AC-C05: 지도·목록에서 같은 신고의 담당·상태를 일관되게 확인할 수 있습니다.

## 미정

위험도 변경 후 사용할 임계 기준, 자동 승격 여부·반복 규칙, 상단 고정과 필터 제외의 우선순위, 미확인끼리의 정렬, 전체 건수의 취소 포함 여부, 지도 실패 안내·위치 오차 표현·갱신 주기, 모의 기능 화면의 구체 범위는 미정입니다.
