[PRD](../prd/index.md)가 정해지면 기능별 문서를 이 폴더에 만들고 아래 목록에 연결합니다.

## 명세 목록

아직 없음.

## 작성 항목

- 상태와 관련 요구사항
- 목적·범위
- 사용자 시나리오와 화면 동작
- 로딩·빈 상태·오류·예외 처리
- 관련 기술 계약
- 인수 조건과 미결정 사항

API 필드·DB 제약은 [기술 명세](../specs/index.md)에 정의하고 링크합니다.
문서 유지 방법은 [SOT](../sot.md)를 참고합니다.
