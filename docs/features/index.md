# 기능 명세

서비스와 기능 범위는 아직 미정이며 작성된 기능 명세는 없습니다.
[PRD](../prd/index.md)가 정해지면 기능별 문서를 이 폴더에 만들고 아래 목록에 연결합니다.

## 명세 목록

아직 없음.

## 작성 항목

- 상태와 관련 요구사항
- 목적·범위
- 사용자 시나리오와 화면 동작
- 로딩·빈 상태·오류·예외 처리
- 관련 API·DB·외부 연동 계약
- 인수 조건과 미결정 사항

사용자에게 제공할 동작·업무 규칙·완료 조건은 이 폴더에서 관리합니다.
API 경로·요청·응답은 [API 명세](../api/index.md), 저장 구조·제약은 [DB 명세](../db/index.md), 외부 제공자와의 통신 규칙은 [외부 연동 명세](../integrations/index.md)에 정의하고 필요한 문서만 연결합니다. 계약 본문을 기능 명세에 복사하지 않습니다.
문서 유지 방법은 [SOT](../sot.md)를 참고합니다.
