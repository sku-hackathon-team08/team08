# 아키텍처

> 상태: 백엔드 프레임워크·환경 관리·로컬 DB 확정. 프론트 스택과 배포 DB는 미정입니다.
> 기술 선택을 기록한 문서이며 앱·DB 연결의 구현 완료를 뜻하지 않습니다.

|---|---|---|
| [frontend/](../frontend/) | 프론트엔드 코드 | 미정 |
| [backend/](../backend/) | 백엔드 코드 | Python · FastAPI |

## 저장소와 애플리케이션 경계

저장소는 프론트와 백엔드를 함께 관리하는 모노레포입니다.
백엔드는 모놀리식 아키텍처를 사용하며, 기능별 코드를 모듈로 나누되 하나의 FastAPI 애플리케이션에서 실행합니다.
기능마다 독립 서비스나 별도 배포 단위를 만들지 않습니다.

```text
team08/                       # 모노레포
├── frontend/                 # 프론트엔드
├── backend/                  # 하나의 FastAPI 애플리케이션
│   └── 기능별 모듈           # 내부 폴더 구분, 상세 이름·계층은 미정
└── docs/                     # 공통 요구사항·설계·가이드
```

모듈은 기능과 책임을 구분하기 위한 내부 코드 경계입니다. 실제 폴더명·라우터·서비스·DB 접근 계층은 스캐폴딩에서 정합니다.
프론트 정적 파일을 백엔드에서 제공할지, 프론트를 별도로 배포할지는 아직 정하지 않았습니다.
프론트 배포 방식과 백엔드의 모놀리식 구성은 별도로 기록합니다.

## 백엔드 환경과 DB

| 항목 | 선택 | 상태 |
|---|---|---|
| 웹 프레임워크 | FastAPI | 확정 |
| 가상환경·의존성 관리 | uv | 확정 |
| 로컬 개발 DB | SQLite | 확정 |
| 배포 DB | PostgreSQL 검토 | 후보, 미확정 |

uv로 백엔드의 가상환경과 의존성을 관리합니다. 실제 Python·도구 버전과 설치·실행 명령은
스캐폴딩에서 정한 뒤 [백엔드 README](../backend/README.md)에 기록합니다.

PostgreSQL을 배포 DB로 채택할 경우 연결 설정·드라이버·스키마 관리 방식과 해당 DB에서의 통합 검증을 함께 정합니다.
현재 ORM·DB 드라이버·동기 또는 비동기 접근·마이그레이션 도구는 미정입니다.
