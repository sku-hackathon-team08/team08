# 아키텍처

> 상태: 백엔드 레이어 기반 모놀리식·프레임워크·환경 관리·로컬 DB 확정. 프론트 스택과 배포 DB는 미정입니다.
> 기술 선택을 기록한 문서이며 앱·DB 연결의 구현 완료를 뜻하지 않습니다.

|---|---|---|
| [frontend/](../frontend/) | 프론트엔드 코드 | 미정 |
| [backend/](../backend/) | 백엔드 코드 | Python · FastAPI |

## 저장소와 애플리케이션 경계

저장소는 프론트와 백엔드를 함께 관리하는 모노레포입니다.
백엔드는 **레이어 기반 모놀리식**으로 구성합니다. 기술적 역할을 기준으로 폴더를 나누고,
각 레이어 안에서 기능별 파일 또는 하위 패키지로 구분합니다. 전체 백엔드는 하나의 FastAPI 애플리케이션으로 실행·배포합니다.

예상 개발 규모가 크지 않아 코드의 역할과 위치를 쉽게 찾을 수 있는 구성을 선택했습니다.
프론트 정적 파일을 백엔드에서 제공할지, 프론트를 별도로 배포할지는 아직 정하지 않았습니다.

## 백엔드 레이어 구성

아래는 스캐폴딩의 배치 기준입니다. 현재 해당 앱 파일이 구현된 상태는 아니며, 필요한 책임이 생길 때 생성합니다.
`<기능>`은 설명용 자리표시자이며 서비스 기능을 미리 정의하지 않습니다.

```text
backend/app/
├── main.py                  # 앱 생성·라우터 조립
├── core/                    # 공통 설정·공통 오류
├── api/
│   └── routes/<기능>.py     # HTTP 요청·응답 처리
├── schemas/<기능>.py        # 요청·응답 검증과 데이터 구조
├── services/<기능>.py       # 기능 흐름·비즈니스 로직
├── repositories/<기능>.py   # DB 조회·저장 분리 필요 시 추가
├── models/<기능>.py         # 영속 데이터 모델
└── db/                      # DB 연결·세션 등 실행 기반
```

| 레이어 | 책임과 경계 |
|---|---|
| API 라우터 | HTTP 입력·응답·의존성 연결을 담당하고 비즈니스 로직은 서비스에 위임 |
| 스키마 | 요청·응답의 타입·형식 검증. 영속 모델과 역할 구분 |
| 서비스 | 기능 규칙·작업 흐름을 조합하며 API 라우터에 의존하지 않음 |
| 리포지토리 | 필요할 때 DB 접근을 분리. 서비스·라우터를 호출하지 않음 |
| 모델·DB | 저장 구조와 연결 기반. 상위 HTTP 처리 로직에 의존하지 않음 |
| 공통 설정 | 앱 전체에 필요한 설정·공통 오류. 특정 기능 로직을 모으는 폴더로 사용하지 않음 |

기본 호출 방향은 라우터 → 서비스 → DB 접근입니다. 리포지토리를 분리하면 서비스 → 리포지토리 → DB로 연결합니다.
단순한 초기 기능은 서비스에서 DB에 접근할 수 있으며, 중복 쿼리나 독립적으로 관리할 책임이 생기면 리포지토리로 분리합니다.
단순 전달만 하는 계층·범용 베이스 클래스·인터페이스를 미리 만들지 않습니다.

각 레이어에서 동일 기능은 같은 이름을 사용합니다. 파일이 커지면 해당 레이어 안에서 기능별 하위 패키지로 나눕니다.
작업은 한 기능의 라우터·서비스·스키마·데이터 접근을 함께 완성하는 단위를 권장합니다.
공통 앱 조립·설정·DB 연결 파일의 동시 변경은 담당자끼리 조율합니다.

## 백엔드 환경과 DB

| 항목 | 선택 | 상태 |
|---|---|---|
| 웹 프레임워크 | FastAPI | 확정 |
| 가상환경·의존성 관리 | uv | 확정 |
| 로컬 개발 DB | SQLite | 확정 |
| 배포 DB | PostgreSQL 검토 | 후보, 미확정 |

uv로 백엔드의 가상환경과 의존성을 관리합니다. 실제 Python·도구 버전과 설치·실행 명령은
스캐폴딩에서 정한 뒤 [백엔드 README](../backend/README.md)에 기록합니다.

PostgreSQL을 배포 DB로 채택할 경우 연결 설정·드라이버·스키마 관리 방식과 해당 DB에서의 통합 검증을 함께 정합니다.
현재 ORM·DB 드라이버·동기 또는 비동기 접근·마이그레이션 도구는 미정입니다.
